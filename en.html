    Frequently asked questions

    Before we get started.

    How much does a website cost?

    It depends on the number of pages, content, design, features and integrations. Use the estimate tool for an initial range; a formal proposal requires a scope review.

    Can you work with an existing website?

    Yes, depending on the technology, access permissions and condition of the current site. We first assess what can be improved.

    Will my website work on mobile?

    Responsive layouts are part of our proposed approach. Actual devices and key user journeys should be tested before launch.

    Do you offer ongoing maintenance?

    Maintenance can be arranged separately with defined updates, exclusions and response times.

    Can you help clients outside Spain?

    We can discuss remote projects in English or Spanish. Project scope, billing, taxes and contractual requirements must be confirmed before any engagement.
