# Impulsa tu Negocio — web pública

Sitio de presentación para servicios de diseño web dirigidos a pequeños negocios y autónomos de Elche y Alicante.

## Contenido
- `index.html`: página principal.
- `portfolio/restaurante.html`: demostración ficticia de web para restaurante.
- `portfolio/servicios.html`: demostración ficticia para negocio de servicios.
- `portfolio/tienda-online.html`: demostración interactiva de catálogo, sin pagos ni pedidos reales.
